# davidguevara.dev

Personal site and app privacy policies.

## Structure

```
index.html                          → davidguevara.dev
css/, js/, fonts/                   → site assets
litescraper/
  icon.png                          → liteScraper app icon
  privacy/index.html                → davidguevara.dev/litescraper/privacy/
litefin/privacy/index.html          → davidguevara.dev/litefin/privacy/
vaportracker/privacy/index.html     → davidguevara.dev/vaportracker/privacy/
enhancerforreddit/privacy/index.html → davidguevara.dev/enhancerforreddit/privacy/
vr/                                 → davidguevara.dev/vr/
```

## Apps

- **liteFin** — tvOS Jellyfin client · [App Store](https://apps.apple.com/us/app/litefin/id6777851924) · [Privacy Policy](https://davidguevara.dev/litefin/privacy/)
- **Vapor Tracker** — Steam price tracker (IsThereAnyDeal lookups, no server, no analytics) · [Privacy Policy](https://davidguevara.dev/vaportracker/privacy/)
- **Enhancer for Reddit** — Safari extension for old.reddit.com · [App Store](https://apps.apple.com/us/app/enhancer-for-reddit/id6763678868) · [Privacy Policy](https://davidguevara.dev/enhancerforreddit/privacy/)
